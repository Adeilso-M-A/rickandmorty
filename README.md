# Portal Rick and Morty - FPFtech

Aplicativo Android desenvolvido para catalogar entidades da API Rick and Morty com suporte offline-first.

## Credenciais de Acesso (Teste)
* **Usuário:** admin
* **Senha:** admin123

## Tecnologias Utilizadas
* Kotlin & Jetpack Compose (UI)
* Retrofit + Gson (Rede)
* Room Database (Persistência local / Offline-first)
* Coroutines & Flow (Concorrência e Reatividade)
* WorkManager (Sincronização periódica)
* Foreground Service (Sincronização manual)
* FusedLocationProviderClient (Geolocalização)
* Coil (Carregamento de imagens)

## Como Executar
1. Clone o repositório.
2. Abra no Android Studio (versão recomendada: Iguana/Jellyfish ou superior).
3. Execute o app em um emulador ou dispositivo físico com API 26+.
